## Las 7 apps analizadas

### 1. Hopper

- **Modelo**: app móvil predictivo. "Compra ahora" o "espera, bajará".
- **Precio**: gratis básico, freezing price $5-15.
- **Pro**: predicciones algoritmo decentes, UI excelente mobile, "price match guarantee" beta.
- **Contra**: opta por hoteles + ancillaries (no es pure cazador).
- **Alerta velocidad**: media-rápida (3-15min retraso vs precio real).

### 2. Skyscanner

- **Modelo**: meta-buscador (compara aerolíneas + OTAs).
- **Precio**: gratis.
- **Pro**: catálogo amplio, "everywhere" search innovador (busca destinos baratos desde tu origen).
- **Contra**: alertas precio lentas (30-60min). No optimizado para error fares.
- **Alerta velocidad**: lenta (15-45min retraso).

### 3. Going (anteriormente Scott's Cheap Flights)

- **Modelo**: newsletter curado por humanos + email alertas.
- **Precio**: Premium €49/año (recomendado). Limited gratis.
- **Pro**: el **mejor para error fares** (humanos detectan + envían en 5-15min).
- **Contra**: solo email (no push), no app robusta.
- **Alerta velocidad**: media-rápida (5-30min).
- **Mercado**: principal USA. Cobertura España mejorando 2025-2026.

### 4. Google Flights

- **Modelo**: meta-buscador Google.
- **Precio**: gratis.
- **Pro**: rápido, integrado Google, tracking "save" decent.
- **Contra**: no aplicación robusta error fares. Solo tracking precio.
- **Alerta velocidad**: media (15-30min).

### 5. Kayak

- **Modelo**: meta-buscador clásico + price alerts.
- **Precio**: gratis core, Kayak Plus opcional.
- **Pro**: histórico precios bueno, "price forecast" decente.
- **Contra**: alertas confusas, no destacable.
- **Alerta velocidad**: lenta (30-60min).

### 6. Kiwi

- **Modelo**: OTA agregador + alerts.
- **Precio**: gratis core, premium opcional.
- **Pro**: amplia red rutas con combinaciones complejas (multi-stop, virtual interlining).
- **Contra**: alertas tardías + UI confusa + servicio post-compra mediocre.
- **Alerta velocidad**: lenta (45-90min).

### 7. TripCazador (Telegram + email)

- **Modelo**: Telegram (canal real-time) + email digest semanal.
- **Precio**: gratis core, plan Premium €2.99/mes opcional.
- **Pro**: **el más rápido en mercado español** (alertas push 3-8min de detectar drop). Curated por equipo + algoritmo. **Concierge €19** opcional para alta personalización.

## Errores comunes con apps de alertas

### Error 1: solo 1 app

Pierdes 30-40% error fares con 1 sola app. **Mínimo 2 apps complementarias**.

### Error 2: alertas con threshold muy bajo

Si pones "MAD-Tokio bajo €300", **nunca te alertará** (no llega tan bajo). Ajusta threshold realista (€520-580 ruta Asia).

### Error 3: ignorar email/push

Te llega alerta a las 11:47am pero estás reunión + abres email 18:30 → error fare desaparecido.

**Cómo evitar**: configura push prioritarios (TripCazador Telegram + Hopper) que rompan modo "no molestar" si urgente.

### Error 4: confiar en "precio histórico"

Hopper / Kayak predicen "subirá/bajará". **Algoritmos fallan 30-40%** en mercado volátil. Úsalos como **indicador, no decisión final**.

### Error 5: comparar precios con caché viejo

Algunas apps muestran precios cachéd 30-60min antes. Cuando intentes reservar = precio diferente. **Verifica en la web de aerolínea final** antes pagar.

## FAQ Apps alertas precios

### ¿De verdad las apps avisan antes que ver Skyscanner manualmente?

**Sí, drásticamente más rápido** durante error fares. Manual = chequeas 1x/día = pierdes 50% error fares (duración promedio 30-90min). App push = 4-15min reacción = cazas la mayoría.

### ¿Push notifications funcionan en modo "no molestar"?

**Configurable**: si marcas TripCazador / Hopper como "VIP" en iOS / Android, **rompen DND**. Apps por defecto NO rompen DND.

### ¿Cómo activar alertas iOS / Android para que funcionen mejor?

iOS:
1. Ajustes → Notificaciones → [App].
2. Activar "Sonidos" + "Mostrar en pantalla bloqueada".
3. Marcar como "Importante" en ajustes especiales.

Android: similar, configurar canal "importante" + override DND.

### ¿Las apps comparten mis datos personales?

**Sí, todas en mayor o menor medida**. Para alertas funcionar, requieren tu email + búsquedas + rutas seguidas. Lee política privacidad. **TripCazador** Telegram canal no requiere registro email (puedes seguir anónimo).

### ¿Pagar Going Premium o TripCazador Premium primero?

Si **solo viajas español/EU**: **TripCazador Premium €2.99/mes** primero. Si vuelas USA/larga internacional: **Going Premium €49/año** primero. Si ambos: combina (€85/año total).

### ¿Apps gratuitas son "trampa" con precios falsos?

No típicamente. Tanto Hopper como Google Flights muestran precios reales. Trampa común: **al hacer click reserva**, te llevan a OTA con comisión añadida que sube precio €10-30. **Compra directo aerolínea** siempre.
