🔎 Qué falta conectar en la arquitectura

  1. El motor escribe JSON plano pero aún no graba en Postgres — db.py existe en SQLite, hay que migrar.
  2. La API lee del JSON, no de Postgres — correcto para el MVP, pero bloquea métricas históricas y alertas de usuario.
  3. El cron worker no envía aún a Telegram deals individuales — el código existe en notifier.py, falta cablearlo al export.
  4. No hay CDN de imágenes — las tarjetas cargan Unsplash directo (riesgo de rate limit).

4. Bloqueos agregados — lo que necesito de ti

Ordenado por prioridad. Los 4 P1 son lo único que impide el primer deploy público y las primeras comisiones.

🔴 P1 · Dominio tripcazador.com

Sin dominio no hay web, ni SEO, ni SSL, ni email profesional.

Cómo: Porkbun o Cloudflare Registrar. ~10€/año. 15 minutos.

🔴 P1 · TP_MARKER de Travelpayouts

Sin marker, todas las URLs de afiliación redirigen sin tu ID y no se paga comisión.

Cómo: login en travelpayouts.com → Profile → copy "Marker ID" numérico. 2 minutos.

🔴 P1 · VPS Hetzner CX22 + cuenta Vercel

Hosting del backend (API, worker, DB) y del frontend respectivamente.

Cómo: Hetzner Cloud → CX22 Ubuntu 24.04 Nuremberg (4.15€/mes). Vercel free con login GitHub.

🔴 P1 · Canal Telegram @tripcazador + bot via @BotFather

Es el primer canal de distribución orgánica (más rápido que SEO).

Cómo: Telegram → Crear canal público @tripcazador. Luego @BotFather → /newbot → "TripCazadorBot" → copiar token y chat_id del canal.

🟠 P2 · Dirección estética del logo

Sin logo no puedo generar favicon, OG images ni posts sociales.

Cómo: responde con 1 palabra — tech, aventura o híbrido — y yo genero 3 variaciones con canvas-design.

🟠 P2 · Repo GitHub + GA4 Property ID

Necesarios para CI/CD y analytics desde día 1.

Cómo: GitHub → New repo "tripcazador" (privado). Google Analytics → crear propiedad → copiar G-XXXXXXXXXX.

🟠 P2 · Decisión: ¿activamos hoteles ahora o después?

Duplica el inventario de deals pero añade complejidad (scraper Booking + credenciales afiliado).

Cómo: decide sí/no. Si sí, abrir cuenta Booking Affiliate en paralelo (no bloquea).

🟡 P3 · Datos para textos legales

RGPD y AdSense exigen aviso legal, política de privacidad y cookies.

Cómo: dime nombre completo o razón social, email contacto, país fiscal. Yo genero los textos.

🟡 P3 · Instagram + Beehiiv (cuentas)

Canales de marketing secundarios. No bloquean el MVP.

Cómo: Instagram business @tripcazador. Beehiiv free tier.
