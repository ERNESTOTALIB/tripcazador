🚀 Próximos 3 pasos críticos para tener algo live

PASO 1 — Hetzner + DNS (30 min)
Crear VPS Hetzner CX22, instalar Docker, clonar repo, rellenar .env.production, ejecutar docker-compose up -d. Configurar Cloudflare DNS.
PASO 2 — Vercel + Dominio (15 min)
Importar tripcazador-web/ en Vercel, añadir NEXT_PUBLIC_API_URL, conectar tripcazador.com via CNAME en el registrar del dominio.
PASO 3 — Keys + TP_MARKER (10 min)
Rellenar KIWI_API_KEY, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID y TP_MARKER en .env.production. El motor empieza a buscar y enviar alertas automáticamente.

1 Marca y Posicionamiento

Construir una marca reconocible en el nicho de chollos de viaje en España y mercado hispano.
TripCazador
tripcazador.com · tripcazador.com

🎯 Audiencia primaria

Viajeros de 28-50 años en Alemania, Suiza, Austria, Alsacia. Hablan español o alemán. Quieren viajar 2-4 veces al año. Priorizan precio pero no sacrifican comodidad. Usuarios de Skyscanner y Booking pero no tienen tiempo de monitorizar precios.

🌍 Expansión de audiencia

Fase 1: hispanohablantes en DACH (Alemania/Austria/Suiza). Fase 2: toda España + Portugal. Fase 3: mercado europeo en inglés. La comunidad hispanohablante en Europa central es nicho desatendido por Viajeros Piratas (enfocado en España peninsular).

🗣️ Tono de voz

Amigo experto, no corporativo. "Oye, acabo de cazar esto para ti" — directo, emocionante, con contexto real. Sin clickbait, con datos. Si hay una oferta: precio exacto, aerolínea, fechas, ratio vs. precio normal. Sin exageraciones.

📱 Identidad visual

Ámbar/dorado + negro profundo. Minimalismo con datos. El logo: un halcón (cazador) estilizado con alas en forma de gráfico de precio cayendo. Cards de oferta con estética "pantalla de vuelo" — como un radar que detecta una presa.

2 Modelo de Monetización

Stack de ingresos diversificado, empezando por afiliación desde el día 1 y escalando hacia premium y B2B.

✈️ Afiliación Vuelos

2-6% por reserva
Día 1 — Travelpayouts ya integrado

Travelpayouts paga comisión por cada reserva completada via link de afiliado. Ya tenemos la API — solo hay que activar el programa de afiliados y añadir UTM parameters a los links de resultados.

🏨 Afiliación Hoteles

4% por noche
Mes 1 — Booking.com + Hotels.com

Booking.com Affiliate Partner: 4% de comisión. El motor de hoteles ya genera resultados — activar links de afiliado. Con 10 reservas/mes de 100€/noche = 40€. Escala linealmente.

📢 Canal Telegram Premium

5-9€/mes por usuario
Mes 2 — Canal con alertas prioritarias

Canal gratuito con ~24h de retraso. Canal premium con alertas en tiempo real + deals exclusivos de Business class + notificaciones push. Modelo como Scott's Cheap Flights o Jack's Flight Club.

📧 Newsletter Premium

7€/mes o 59€/año
Mes 3 — Lista de correo curada

Newsletter semanal gratuita con top 5 deals. Newsletter premium diaria con todos los deals + análisis de tendencias + guías de destino exclusivas. Substack o Beehiiv (mejor para ingresos).

🎯 Display Advertising

2-5€ CPM
Mes 4 — Google AdSense → Mediavine

Al principio AdSense (accesible desde el día 1). Con 50k visitas/mes calificar para Mediavine (RPM superior, 20-35€). Los posts SEO de "mejor época para viajar a X" generan tráfico orgánico rentable.

🤝 Contenido Patrocinado

200-1.500€ por post
Mes 6+ — Una vez con audiencia

Agencias de viaje, seguros de viaje (IATI, Chapka), tarjetas de crédito viajeras, aplicaciones de viaje. Solo marcas alineadas con valores — sin spam. Precio según seguidores y engagement.

🏢 API B2B / White-label

99-499€/mes
Año 2+ — Para agencias y RRHH

El motor de búsqueda empaquetado como servicio para agencias de viaje corporativas, departamentos de RRHH que gestionan viajes de empresa, o blogs de viaje que quieren integrar alertas.

🎒 Actividades y Seguros

8-15% por venta
Mes 4 — GetYourGuide + IATI

GetYourGuide/Viator: 8% en tours y actividades. IATI Seguros: 15-20% en seguros de viaje. Complementa perfectamente los deals de vuelo+hotel — el usuario ya está comprando el viaje.

✓ Dudas Resueltas — Decisiones Tomadas

Respuestas definitivas a las preguntas abiertas del plan. Actualizadas 2026-04-18.

CERRADO ¿Usar Amadeus GDS para cubrir Eurowings, Condor, TUIfly?

NO. Amadeus cerró registros de nuevas cuentas en 2025. No hay forma de registrarse ni obtener credenciales. Solución definitiva: Kiwi/Tequila API cubre virtualmente todas las aerolíneas del mundo (750+, incluyendo Eurowings y Condor via GDS de Kiwi). Complementar con RapidAPI Sky Scrapper para rutas específicas. Eliminar cualquier referencia a activar Amadeus de las prioridades.

RESUELTO ¿Crontab del sistema, APScheduler o solución propia para los runs periódicos?

Loop Python en cron_runner.py. Razón: más portable en Docker (no depende de crontab del sistema ni de librerías extra). El worker arranca, ejecuta inmediatamente, luego duerme CRON_INTERVAL segundos (default: 21600 = 6h). Configurable via variable de entorno. Logs centralizados en /app/output/worker.log.

RESUELTO ¿Necesitamos Nginx como reverse proxy en el servidor?

No para el MVP. Cloudflare actúa como proxy/CDN/WAF en la capa pública. FastAPI con uvicorn (2 workers) expone directo al puerto 8000. Docker mapea el puerto al host. Cloudflare → Puerto 443 → Docker puerto 8000. Añadir Nginx si se necesita SSL termination local o múltiples servicios web en un VPS.

RESUELTO ¿Migrar de SQLite a PostgreSQL ahora o más adelante?

PostgreSQL desde el día 1 en producción. Ya está dockerizado en docker-compose.yml (postgres:15-alpine + volumen persistente). El worker sigue usando SQLite localmente para historial de búsquedas. La API FastAPI lee deals.json (no SQL directo) — esto permite escalar sin cambiar el motor de búsqueda. sql/init.sql creado con 9 tablas (flights, anomalies, price_history, deals, hotels, user_alerts, notification_log, api_calls_log, airlines), 2 vistas (top_deals_today, price_stats_by_route) y trigger de updated_at.

RESUELTO ¿Por qué todos los deals aparecían como CRÍTICO (score=100)? ¿Cómo calibrar el detector?

Causa: T0 (precio absoluto) era demasiado sensible para low-cost. Un vuelo Ryanair de 15€ MRS→PMI es normal, no un error fare. Solución aplicada: (1) LOWCOST_AIRLINES set (FR, U2, W6, VY, etc.) con umbrales T0 permisivos (corto=8€, medio=30€, largo=80€ vs los umbrales standard más altos). (2) Para clasificar como CRÍTICO, low-cost requiere 3 técnicas activas (vs 2 para aerolíneas regulares). Resultado: clasificaciones realistas.

RESUELTO ¿Las API keys se filtran en logs o en el HTML generado? (Track 3)

Protegidas. Todas las keys se cargan desde .env via python-dotenv (nunca hardcodeadas). El HTML report no incluye ninguna key. La API FastAPI no expone secrets en respuestas. Docker lee secrets de .env.production (en .gitignore). Pendiente Track 3: audit con detect-secrets + pre-commit hook que bloquee commits con API keys detectadas.

RESUELTO ¿Cómo validar datos de entrada a la API FastAPI? ¿Rate limiting? (Track 3)

Pydantic models en api/main.py. El modelo Deal valida todos los campos del deals.json. Los query params (origin, destination, cabin, classification) son strings con valores posibles validados por FastAPI. CORS configurado para solo tripcazador.com + localhost:3000. Pendiente: rate limiting con slowapi (max 60 req/min por IP) — tarea del Track 3.

RESUELTO ¿Qué formato tiene deals.json para conectar backend con web? ¿Versión del schema?

deals.json v4.1 generado por deals_exporter.py. Contiene: schema_version, generated_at, stats (total, critico, error, anomalia), deals[] con campos: id, type, origin, destination, airline, price_eur, cabin, date_out, date_back, nights, duration_min, classification, score, headline, tags, image_url, lat, lon, expires_at, booking_url, verified (true si 2+ fuentes confirman precio ±10%). También guarda historial en output/history/deals_YYYYMMDD_HHMM.json.

PENDIENTE MANUAL ¿Cómo conectar Vercel con el dominio tripcazador.com?

vercel.json creado en tripcazador-web/ con: rewrites de /api/* → FastAPI en Hetzner, headers de seguridad (HSTS, X-Frame-Options, CSP), caché agresiva para assets estáticos, región fra1 (Frankfurt, más cercana al target DACH). Para desplegarlo: (1) Push repo a GitHub. (2) Importar en vercel.com → "New Project" → seleccionar tripcazador-web/. (3) Añadir variable NEXT_PUBLIC_API_URL=https://api.tripcazador.com. (4) DNS: CNAME "www" → cname.vercel-dns.com y A "@" → 76.76.21.21. El CI/CD de Vercel es automático (GitHub integration).

PENDIENTE ¿Cómo funcionará el blog con artículos SEO?

Pendiente crear app/blog/[slug]/page.tsx en tripcazador-web/. El plan: archivos .mdx en /content/blog/. Next.js 14 con @next/mdx o contentlayer. Estructura de cada artículo: H1 con keyword ("Vuelos baratos a Tanzania desde Basilea"), tabla de precios por mes (data del motor), temporadas, FAQ Schema.org para rich snippets. Prioridad alta para SEO — es la principal fuente de tráfico orgánico.
